# Bjmembers1-ops Tap

## How do I install these formulae?

`brew install bjmembers1-ops/tap/<formula>`

Or `brew tap bjmembers1-ops/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bjmembers1-ops/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
